**Architecture:** 改动集中在 4 个源文件：`components/tg/native.tsx`（核心：`Group`/`Cell`/`Segmented` 三个共享组件重新设计，`Section`/`Bubble` 不动）、`app/page.tsx`（首页 TG 分支唯一一处手写页头，改用已有的 `PageHeader` 组件）、`chart/SpiritPanel.tsx`（气泡渲染改用共享 `Bubble`）、`fengshui/DwellingForm.tsx`（删除本地 `OptionButtons`，两处调用统一改用重新设计后的 `Segmented`）。其余 10 个业务页面（`chart/page.tsx`、`dream/page.tsx`、`account/page.tsx`、`profiles/page.tsx`、`reading/page.tsx`、`fengshui/page.tsx`、`fengshui/ObjectAdvisorForm.tsx`、`fengshui/dwellings/page.tsx`）已经全部通过 `import { Group, Cell, Segmented } from "@/components/tg/native"` 调用共享组件、且已经全部用 `PageHeader` 渲染页头——**这些文件的 JSX 一行都不用改**，它们在 Task 1 完成后自动获得新样式。

**Tech Stack:** Next.js 16 App Router + React 19 + Tailwind 4 + TypeScript；测试用 Vitest + `@testing-library/react`（jsdom 环境，已在 `apps/web/vitest.config.ts` 配置好，`globals: true` 但本仓库测试文件习惯上仍显式 `import { describe, it, expect } from "vitest"`，请沿用这个习惯而不是依赖全局注入）。

#### Step 11: 实现 `Segmented`

替换现有 `Segmented` 函数为（`onKeyDown`/`listRef`/方向键漫游逻辑完全不动，只改 `return` 里的 JSX 和 style）：

```tsx
export function Segmented<T extends string>({
  options,
  value,
  onChange,
  idBase,
  ariaLabel,
}: {
  options: readonly { value: T; label: React.ReactNode }[];
  value: T;
  onChange: (v: T) => void;
  idBase?: string;
  ariaLabel?: string;
}) {
  const listRef = React.useRef<HTMLDivElement>(null);

  function onKeyDown(e: React.KeyboardEvent) {
    if (!idBase) return;
    if (e.key !== "ArrowRight" && e.key !== "ArrowLeft") return;
    e.preventDefault();
    const idx = options.findIndex((o) => o.value === value);
    const next =
      e.key === "ArrowRight"
        ? (idx + 1) % options.length
        : (idx - 1 + options.length) % options.length;
    onChange(options[next]!.value);
    listRef.current
      ?.querySelectorAll<HTMLButtonElement>('[role="tab"]')
      [next]?.focus();
  }

  return (
    <div
      ref={listRef}
      role={idBase ? "tablist" : "group"}
      aria-label={ariaLabel}
      onKeyDown={onKeyDown}
      className={idBase ? "flex gap-1" : "flex gap-2"}
    >
      {options.map((o) => {
        const active = o.value === value;
        return (
          <button
            key={o.value}
            type="button"
            {...(idBase
              ? {
                  role: "tab",
                  id: `${idBase}-tab-${o.value}`,
                  "aria-selected": active,
                  "aria-controls": `${idBase}-panel-${o.value}`,
                  tabIndex: active ? 0 : -1,
                }
              : { "aria-pressed": active })}
            onClick={() => onChange(o.value)}
            className={
              idBase
                ? "px-3 py-2 text-[14px]"
                : "flex-1 rounded-[var(--radius-button)] border py-2 text-[14px]"
            }
            style={
              idBase
                ? {
                    color: active ? "var(--color-cinnabar)" : "var(--color-ink-2)",
                    borderBottom: active ? "2px solid var(--color-cinnabar)" : "2px solid transparent",
                  }
                : {
                    borderColor: active ? "var(--color-cinnabar)" : "var(--color-line)",
                    color: active ? "var(--color-cinnabar)" : "var(--color-ink)",
                  }
            }
          >
            {o.label}
          </button>
        );
      })}
    </div>
  );
}
```

**注意**：组模式（无 `idBase`）的 `className` 里必须包含 Tailwind 的 `border`（提供默认 1px solid 边框宽度），实际颜色只由 `style.borderColor` 控制——这跟 `fengshui/DwellingForm.tsx` 里现有的 `OptionButtons`（Task 4 会删除它）写法完全一致，直接照抄它的 class/style 组合，不要自创新写法。
